# Fibonacci Series 🐍

A simple Python program that generates and prints the first 10 numbers of the Fibonacci sequence using an iterative approach.

## 📌 Project Description

This project demonstrates a basic implementation of the Fibonacci sequence in Python.

The program initializes two variables, `a = 0` and `b = 1`, and repeatedly calculates the next Fibonacci number using their sum. The current program runs the loop 10 times and prints each generated value.

## ✨ Features

* Simple and beginner-friendly Python implementation
* Generates the Fibonacci sequence iteratively
* Uses a `for` loop for repetition
* Prints the sequence in a single line
* No external libraries are required

## 🛠️ Installation

No additional installation or Python packages are required.

Make sure **Python 3.x** is installed on your system.

Check your Python version with:

```bash
python --version
```

Or:

```bash
python3 --version
```
